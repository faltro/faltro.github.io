FALTRO / rclone / privacy policy

Last updated: 2026-11-12

Overview

This privacy policy describes how the FALTRO rclone Google API client ("the app") handles data. The app is a personal OAuth client used exclusively by its owner to access their own Google Drive through rclone. It is not offered to the public.

Data accessed

When authorized, the app may access files and metadata in the authorizing user's Google Drive, within the scopes granted during sign-in. This access is used solely to perform file operations (such as listing, uploading, downloading, syncing, and deleting files) explicitly requested by the user through rclone.

Data storage

All data is transferred directly between Google's servers and the user's own computer. OAuth tokens are stored locally in the user's rclone configuration file. No data is sent to, collected by, or stored on any server operated by FALTRO.

Data sharing

No user data is sold, shared with, or transferred to any third party. No data is used for advertising, analytics, or training of any kind.

Google API Services

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account permissions page. Locally stored tokens can be removed by deleting the corresponding remote from the rclone configuration.

Changes

This policy may be updated from time to time. Changes will be posted on this page with an updated date.
